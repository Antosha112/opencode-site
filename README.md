# AURUM Motors — учебный проект

Одностраничный сайт премиального автосалона с отдельными страницами автомобилей.
Без фреймворков и сборки: чистые HTML, CSS и JavaScript.

**Живая версия:** https://antosha112.github.io/opencode-site/

## Структура

```
index.html          — главная: hero, каталог, преимущества, калькулятор, форма
car.html            — страница автомобиля (?id=audi-rs-etron-gt)
assets/
  styles.css        — все стили, переменные, адаптив
  data.js           — массив AURUM_CARS: единственный источник данных
  app.js            — шапка, каталог, фильтры, избранное, калькулятор, форма
  car.js            — рендер страницы автомобиля и похожих моделей
img/                — фотографии (Wikimedia Commons, CC BY-SA 4.0)
```

## Как запустить локально

```powershell
# любой статический сервер, например:
python -m http.server 8000
# затем открыть http://localhost:8000
```

Или просто открыть `index.html` в браузере — но тогда страницы авто
(`car.html?id=...`) лучше проверять через сервер.

## Как это работает

1. `data.js` добавляет в `window` массив машин.
2. `app.js` строит карточки из массива и навешивает обработчики.
3. Фильтр сравнивает `data-cat` карточки с выбранной категорией.
4. Калькулятор считает аннуитетный платёж:
   `P = S * r / (1 - (1 + r)^-n)`, где `r = ставка / 12 / 100`.
5. Форма сохраняет заявки в `localStorage` (ключ `aurum_leads`) — это демо.
6. `car.js` читает `?id=` из адреса, находит машину и заполняет шаблон.

## Как сделать форму настоящей

Замените блок сохранения в `assets/app.js` на отправку:

```js
await fetch("https://formspree.io/f/ВАШ_ID", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ name, phone, car }),
});
```

Аналогично можно отправить заявку в Telegram-бота или свой API.
